# snake-game
Juego 2D en Python con Pygame -- Proyecto Software Factory II

## Descripcion

Juego clasico de Snake desarrollado en Python con Pygame.
La serpiente se mueve automaticamente y el jugaodr la dirige con las flechas del teclado.
El objetivo es comer la mayor cantidad de comida sin chocarse con los bordes ni con el propio cuerpo.

Proyecto individual para la materia Software Factory II.

## Como juagar
1. Al abrir el juego, aparece la pantalla de inicio.
2. Presionar "Jugar" para comenzar.
3. Usar las flechas del teclado para mover la serpiente.
4. Comer la comida (cuadrado rojo) para crecer y suamar puntos.
5. No chocar con los bordes ni con tu propio cuerpo.
6. Al perder, se muestra el puntaje y el ranking.
