# snake-game
Juego 2D en Python con Pygame -- Proyecto Software Factory II

## Descripcion

Juego clasico de Snake desarrollado en Python con Pygame.

El objetivo principal del jugador es guiar a la serpiente para que consuma alimentos o especiales que otorgan puntos extras, aumente su tamaño y acumule la mayor cantidad de puntos posible sin chocar contra los limites del mapa, los obstaculos o su propio cuerpo. Tambien puede elegir entre tres niveles de dificultad (Facil, Medio y Dificil), el jugador dispone de una pausa mediante la tecla P, al finalizar la partida, se muestra el tiempo sobrevivido y los puntajes.

Proyecto individual para la materia Software Factory II.

## Como juagar
1. Al abrir el juego, aparece la pantalla de inicio.
2. Presionar "Jugar" para comenzar.
3. Usar las flechas del teclado para mover la serpiente.
4. Comer la comida (circulo rojo) para aumentar su tamaño y acumule la mayor cantidad de puntos.
5. No chocar contra los limites del mapa o su propio cuerpo.
6. Los obstaculos aleatorios que la serpiente debe evitar.
7. Elegir tres niveles de dificultad (Facil, Medio y Dificil).
8. Dispone de una pausa mediante la tecla P. 
9. Al finalizar la partida, se muestra el tiempo sobrevivido y los puntajes.
