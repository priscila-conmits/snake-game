# Requerimientos — [Snake]

## Requerimientos Funcionales

- RF-01: La serpiente se mueve automáticamente en la dirección actual.
- RF-02: El jugador puede cambiar la dirección usando las teclas de flecha.
- F-03: La serpiente no puede girar 180 grados sobre sí misma.
- RF-04: La comida aparece en posiciones aleatorias de la pantalla.
- RF-05: Cuando la serpiente come la comida, aumenta de tamaño.
- RF-06: El puntaje aumenta cada vez que la serpiente come.
- RF-07: Después de comer, aparece una nueva comida en otra posición aleatoria.
- RF-08: Si la serpiente choca con los bordes, pierde la partida.
- RF-09: Si la serpiente choca con su propio cuerpo, pierde la partida.
- RF-10: Se muestra el puntaje actual durante la partida.
- RF-11: El jugador puede elegir entre tres niveles de dificultad (Fácil, Medio y Difícil).
- RF-12: Existen comidas especiales que otorgan puntos extra.
- RF-13: Aparecen obstáculos aleatorios que la serpiente debe evitar.
- RF-14: El jugador dispone de una pausa mediante la tecla P.
- RF-15: Se guarda el récord más alto alcanzado.
- RF-16: Existe una pantalla de inicio con las opciones Jugar, Ranking y Salir.
- RF-17: Al finalizar la partida, se muestra el tiempo sobrevivido.
- RF-18: El jugador puede reiniciar la partida sin cerrar el juego.

## Requerimientos No Funcionales

- RNF-01: El juego debe ejecutarse a 60 FPS de forma estable.
- RNF-02: Los controles deben responder sin retrasos perceptibles.
- RNF-03: El código debe estar organizado en módulos separados.
- RNF-04: El proyecto debe utilizar Git y GitHub para el control de versiones.
- RNF-05: La ventana del juego debe tener una resolución de 800x600 píxeles.
- RNF-06: Los datos de récords deben almacenarse en SQLite.
- RNF-07: La interfaz debe ser clara y fácil de usar.
- RNF-08: El juego debe funcionar correctamente en Windows 10 y Windows 11.
